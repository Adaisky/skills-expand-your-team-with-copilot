# Mergington High School Activities

A super simple website application that allows students to view and sign up for extracurricular activities.

## Features

- View all available extracurricular activities
- Sign up for activities
- Filter activities by difficulty (Beginner, Intermediate, Advanced, or activities with no difficulty specified)

Activities may include an optional `difficulty` field with the value `Beginner`, `Intermediate`, or `Advanced`. Activities without this field are available at every difficulty level; the `All` filter shows only activities without a specified difficulty.
